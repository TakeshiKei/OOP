# 📘 Object-Oriented Programming (OOP) Repository

Repository ini berisi kumpulan tugas, proyek, dan materi praktikum dari mata kuliah **Object-Oriented Programming (OOP)**.

## 🧠 Deskripsi
Materi OOP yang dipelajari dalam repositori ini meliputi:
- Konsep dasar OOP: Class, Object, Inheritance, Polymorphism, Encapsulation
- Penerapan OOP dalam bahasa Java
- Studi kasus dan implementasi tugas berbasis OOP
